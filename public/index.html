Prefer OBS Text sources? Every value is also written to a .txt file — open the folder.

Go online Offline

Get a public overlay link for OBS anywhere, and control the scoreboard from any phone or PC over the internet.

Needed to open the control panel over the internet. Overlay links don't need it.

Uses a free Cloudflare tunnel: the link changes each time and works while this app is open — unless you use your own tunnel below.

Permanent address: your own Cloudflare tunnel

With a free Cloudflare account and your own domain, the online link stays the same every time — so the live bracket page file you send people keeps working. In the Cloudflare dashboard: Networking › Tunnels › Create Tunnel, pick Windows, and copy the install command (don't run it — BeeboScore Lite runs the tunnel itself). Paste it below, then on the tunnel's Routes tab add a Published application (e.g. bracket.yourdomain.com) with the service URL http://localhost:3200 (3300 for the Testbuild). The token is stored encrypted on this PC.

Performance

How hard BeeboScore Lite works your PC. On a laptop you’re also using for the game or OBS, try Ultra-light first.

✨ Effects engineBeeboFX draws the layouts' effects on your graphics card: real lightning, flames, sparks that glow. Off uses the simpler effects. Ultra-light is for very weak PCs: no glows or looping effects, fewer particles (none on the splash screens), and entrances and transitions that only slide and fade. Auto steps down by itself, all the way to Ultra-light, if your PC can't keep up.
🖥 App window frame rateHow often this window (the live preview) redraws. On a 144 or 240 Hz monitor it would otherwise draw two to four times the frames your stream needs, on the graphics card the game and OBS are using. Overlays in OBS always follow OBS's own frame rate. Kept on this PC.

Keys for events and formatsChange with the format: one row of keys becomes the running format’s (start.gg in 1v1). Everything, in pages: every event’s and format’s keys always sit in the same place; the ▸ key turns the page.
What goes where (Stream Deck XL · 1v1)

One row per job: the match, then every splash — FullVS and GlassVS first, Hide all last — then a row that follows the app (start.gg in 1v1; the format’s keys while a format runs — King of the Hill adds the Leaderboard), then viewer events. Only the third row ever changes. Undo also takes back a format result when that was the last thing. A 15-key Stream Deck gets the match, the splashes, then the format or viewer queue; its VS key plays the VS style chosen in the app — hold it to switch FullVS ⇄ GlassVS.

Not on this PC? Download the plugin file and double-click it on the PC with the Stream Deck.

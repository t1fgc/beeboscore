Uses a free Cloudflare tunnel: the link changes each time and works while this app is open — unless you use your own tunnel below.

Permanent address: your own Cloudflare tunnel

With a free Cloudflare account and your own domain, the online link stays the same every time. In the Cloudflare dashboard: Networking › Tunnels › Create Tunnel, pick Windows, and copy the install command (don't run it — BeeboScore runs the tunnel itself). Paste it below, then on the tunnel's Routes tab add a Published application (e.g. bracket.yourdomain.com) with the service URL http://localhost:3300. The token is stored encrypted on this PC.

Autoscore EXPERIMENTAL

Watches the round markers in your game and gives the set point to whoever wins a game.

⚠ Experimental. Autoscore hasn't been tested at a real tournament yet. Keep an eye on the score, and use Undo auto point if it ever gets one wrong. It's off until you turn it on.
Off
When a game is won

How to turn it on

  1. OBS: Tools → WebSocket Server Settings → tick Enable WebSocket server, then Show Connect Info for the password.
  2. Connect below and pick your game capture source (or a capture card).
  3. Calibrate with ✨ Auto-calibrate below: live, from a video clip, or from 2 screenshots. It finds the round markers and the timer, counts how many rounds win a game and tunes itself. It’s saved, so next time BeeboScore recognises your game by itself.
  4. Flip Autoscore on. Play a game and watch the round counts below.

Calibrate

✨ Auto-calibrateFinds the round markers and the timer, counts how many rounds win a game and tunes the sensitivity, all by itself. Pick whichever is easiest:
🎮 Live

Press it at the start of a game (round 1: full health, no round markers lit), then just play. It’s done once someone wins a round, usually in under a minute.

🎞 A video clip
Round startfightRound won

A recording of your game capture that shows a round start and then someone winning that round. A whole game recorded in OBS is perfect. Anything from 20 seconds to a few minutes, MP4 or WebM.

🖼 2 screenshots

Full-size screenshots of the game capture, in either order. In OBS: right-click the game source › Screenshot (Source).

Videos and screenshots must be of the same game capture you stream, framed the same way (no extra crop, zoom or overlays on top of the HUD).

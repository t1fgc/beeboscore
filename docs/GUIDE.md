# BeeboScore guide

The essentials of BeeboScore: a realtime scoreboard for fighting game streams. Update names, scores and rounds from a clean control panel and your OBS overlay updates instantly. Run team battles and other game formats, pull players and matches straight from **start.gg** and put the bracket and Top 8 on stream, run it from a **Stream Deck**, and **go online** to control it from your phone or another PC.

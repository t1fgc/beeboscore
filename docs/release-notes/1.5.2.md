## BeeboScore 1.5.2

**Download `BeeboScore-1.5.2.exe`** below. Already on 1.5.0 or 1.4.0? Open **Settings → Check for updates** and it fetches this one for you. (The `BeeboScore-Lite-1.5.2.exe` file is the same app, named so 1.5.0 can find it.)

**BeeboScore Lite is BeeboScore again.** Same app, same data folder and sign-ins; only the name changes.

**The red VS logo is back** on the app icon, the starting screen, the panel, the Stream Deck plugin and the docs.

### New: the Layouts tab

Bring in layouts other people made, or make your own.

- **Import a layout:** drop a `.zip`, a folder or a page on the tab. It goes in the **Layout** menu with the app's own and shows in OBS the same way.
- **Your layouts:** preview each one with the scoreboard as it is now, put it on stream, share it as a `.zip`, or remove it (a copy is kept).
- **Make your own:** download the starter layout, a finished scoreboard with every part explained. A layout is a web page with a few `data-sb` attributes, like `<span data-sb="p1.name"></span>`, and every binding is listed in the tab.
- **Layouts from 1.4.0:** Ember, Porcelain and your Overlay maker layouts can come back. Drop their folder from `BeeboScore Data\overlays` on the Layouts tab.

Only import layouts from people you trust: a layout is a web page, and it runs on your PC like any other page.

The full list of changes is in [CHANGELOG.md](https://github.com/t1fgc/beeboscore/blob/main/CHANGELOG.md).

### Windows SmartScreen

The first time you run the exe, Windows may say **"Windows protected your PC"**. Click **More info**, then **Run anyway**. Only do this for a copy downloaded from this Releases page.

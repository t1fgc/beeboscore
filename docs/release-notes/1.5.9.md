## BeeboScore 1.5.9

**Download `BeeboScore-1.5.9.exe`** below. Already on BeeboScore? Open **Settings → Check for updates** and it fetches this one for you. (The `BeeboScore-Lite-1.5.9.exe` file is the same app, named so 1.5.0 can find it.)

### A new Obsidian Glass

- **Obsidian Glass** has a new look for Tekken 8, Street Fighter 6, Avatar Legends and Fatal Fury: black obsidian glass and antique gold, cracks that spread as a player falls behind and mend on a comeback, embers on a winning streak, and a plate that shatters like glass at the end of the set.
- New **Victory**, **Top 8**, **bracket** and **standings** screens in the same glass. On Tekken 8 the sets won show as diamonds by the word **SET**.
- **Your own colours** work on it too: pick **Player 1** and **Player 2** on the Layouts tab to colour each player's own pieces.

Updating swaps the new look in by itself.

The full list of changes is in [CHANGELOG.md](https://github.com/t1fgc/beeboscore/blob/main/CHANGELOG.md).

### Windows SmartScreen

The first time you run the exe, Windows may say **"Windows protected your PC"**. Click **More info**, then **Run anyway**. Only do this for a copy downloaded from this Releases page.

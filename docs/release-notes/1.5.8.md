## BeeboScore 1.5.8

**Download `BeeboScore-1.5.8.exe`** below. Already on BeeboScore? Open **Settings → Check for updates** and it fetches this one for you. (The `BeeboScore-Lite-1.5.8.exe` file is the same app, named so 1.5.0 can find it.)

### Symmetrical player bars

- Player 1's and Player 2's bars are now mirror images: the score box leans the other way on Player 2's side, the set pips start beside the score box on both sides, and the names sit the same distance from it.
- **Obsidian Glass for Tekken 8** shows the sets won as small diamonds that light up with a soft glow, like the old Ember layout.

Layouts you've made in the layout maker get the mirrored bars too.

The full list of changes is in [CHANGELOG.md](https://github.com/t1fgc/beeboscore/blob/main/CHANGELOG.md).

### Windows SmartScreen

The first time you run the exe, Windows may say **"Windows protected your PC"**. Click **More info**, then **Run anyway**. Only do this for a copy downloaded from this Releases page.

## BeeboScore Lite 1.5.0

BeeboScore is now **BeeboScore Lite**: the essentials of BeeboScore in a lighter app, with a Classic layout for each game and start.gg brackets on stream.

**Download `BeeboScore-Lite-1.5.0.exe`** below. Already on 1.4.0? Open **Settings → Check for updates** in the app and it fetches this one for you. (The `BeeboScore-1.5.0.exe` file is the same app, named so 1.4.0 can find it.)

### Moving from 1.4.0

- Your players, pictures, settings and exports are copied into a new **BeeboScore Lite Data** folder next to the exe. The old `BeeboScore Data` folder is left as it was.
- The first-time setup opens once, so you can pick your game's layout.
- **Sign in to start.gg again** on the Bracket tab. Sign-ins are locked to the app that made them.
- The OBS link stays `http://localhost:3300/overlay`, so nothing changes in OBS.
- Install the **BeeboScore Lite** Stream Deck plugin from **Settings → Stream Deck**, press **Set up Stream Deck**, then remove the old *BeeboScore Prototype* plugin in Stream Deck.
- The old exe goes to the Recycle Bin.

### What's in it

- **Five tabs:** Matches, Format, Bracket, Stream and Settings.
- **A Classic layout for each game:** Tekken 8, Street Fighter 6, Avatar Legends and Fatal Fury: City of the Wolves, each kept clear of its game's HUD.
- **start.gg brackets:** pull players and matches onto the scoreboard, put the bracket, Top 8 or standings on stream, share a live bracket page, and send results back to start.gg.
- **Game formats:** Crew Battle, Team Battle, Gauntlet, Team Death Battle, Death Battle, King of the Hill and League. In Team Death Battle, **Undo lock-in** opens the switch window again after a lock-in made too early.
- **FullVS, GlassVS and the victory splash**, with player pictures.
- **Go online** with a password-protected remote control, and **Sign out all devices**.
- **Stream Deck:** **Set up Stream Deck** fills a 15-key Stream Deck or Stream Deck XL for you.
- **Nine control panel looks**, a four-step first-time setup, backups, a self-test and output up to 4K.

### Not in Lite

The Ember and Porcelain layouts and the Overlay maker from 1.4.0 are not part of Lite. Each game has its own Classic layout instead.

The full list of changes is in [CHANGELOG.md](https://github.com/t1fgc/beeboscore/blob/main/CHANGELOG.md).

### Windows SmartScreen

The first time you run the exe, Windows may say **"Windows protected your PC"**. Click **More info**, then **Run anyway**. Only do this for a copy downloaded from this Releases page.

## BeeboScore 1.5.3

**Download `BeeboScore-1.5.3.exe`** below. Already on 1.5.2, 1.5.0 or 1.4.0? Open **Settings → Check for updates** and it fetches this one for you. (The `BeeboScore-Lite-1.5.3.exe` file is the same app, named so 1.5.0 can find it.)

### Only the Classic layouts

- The built-in layouts are called **Classic** in the Layout menu now (they were labelled *Default*).
- Old layouts left over from earlier builds (Frostbite, Venom, Obsidian Glass and the rest, with their game-format versions) are moved out of the Layout menu, once, to `data\retired-layouts` in your data folder. Nothing is deleted: drop one on the **Layouts** tab to bring it back.
- Layouts you imported on the Layouts tab stay. If the layout on stream was one of the old ones, the Classic layout for your game goes on stream.

The full list of changes is in [CHANGELOG.md](https://github.com/t1fgc/beeboscore/blob/main/CHANGELOG.md).

### Windows SmartScreen

The first time you run the exe, Windows may say **"Windows protected your PC"**. Click **More info**, then **Run anyway**. Only do this for a copy downloaded from this Releases page.

## BeeboScore 1.1.6

Already on an older version? Open **Settings → Check for updates** in the app and it will fetch this one for you.

### Fixed

- **Wording.** Typos, punctuation and a few unclear sentences in the app, the README and the guides. Nothing else changed.

Updating from 1.1.5, **Restart & update** now tells you it is installing before the window closes, then shows the starting screen until the new version opens.

Coming from 1.0.0? This version also has everything from 1.1.4 and 1.1.5: ten new layouts, your own VS Splash pictures, splash pictures per player, a starting screen and more. The What's new window lists it all after you update.

### Download

**`BeeboScore-1.1.6.exe`** below. No install: put it in the same folder as your current exe so it keeps your settings.

> [!WARNING]
> Windows may show **"Windows protected your PC"** the first time you run a downloaded copy. Click **More info**, then **Run anyway**. Only do this for a file downloaded from this page.

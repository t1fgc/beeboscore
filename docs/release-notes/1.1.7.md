## BeeboScore 1.1.7

Already on an older version? Open **Settings → Check for updates** in the app and it will fetch this one for you.

### Fixed

- **The window comes back after an update.** After **Restart & update**, the new version's window now comes to the front. Before, Windows could open it behind your other windows, so it looked as if the app had not come back.

### Changed

- **Stream Deck: "Show / hide VS Splash".** The VS Splash key has a clearer name and sits next to "Show / hide overlay" in the Stream Deck app's list. The app updates the plugin for you; if the key is missing, use **File → Install Stream Deck Plugin**.

### New

- **A record of each update.** The app keeps a short `update.log` in its `BeeboScore Data` folder. If an update ever does not reopen the app, that file says how far it got.

Coming from 1.0.0? This version also has everything from 1.1.4 onward: ten new layouts, your own VS Splash pictures, splash pictures per player, a starting screen and more. The What's new window lists it all after you update.

### Download

**`BeeboScore-1.1.7.exe`** below. No install: put it in the same folder as your current exe so it keeps your settings.

> Windows may show **"Windows protected your PC"** the first time you run a downloaded copy. Click **More info**, then **Run anyway**. Only do this for a file downloaded from this page.

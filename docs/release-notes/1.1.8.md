## BeeboScore 1.1.8

Already on an older version? Open **Settings → Check for updates** in the app and it will fetch this one for you.

### Fixed

- **Restart & update opens the new version.** On some PCs the app closed after **Restart & update** and the new version never opened. The new version is now started directly, the same way a double-click starts it.

> [!NOTE]
> This fix takes effect when you update **from** 1.1.8 to a later version. The update **to** 1.1.8 is still done by the version you have now, so if the app closes and does not come back, open `BeeboScore-1.1.8.exe` from the same folder yourself. This is the last time you should need to.

### New

- **A newer version already in the folder.** If a newer BeeboScore exe is already next to the one you are running, **Check for updates** offers to restart into it. Nothing is downloaded.

Coming from 1.0.0? This version also has everything from 1.1.4 onward: ten new layouts, your own VS Splash pictures, splash pictures per player, a starting screen and more. The What's new window lists it all after you update.

### Download

**`BeeboScore-1.1.8.exe`** below. No install: put it in the same folder as your current exe so it keeps your settings.

> [!WARNING]
> Windows may show **"Windows protected your PC"** the first time you run a downloaded copy. Click **More info**, then **Run anyway**. Only do this for a file downloaded from this page.

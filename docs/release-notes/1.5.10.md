## BeeboScore 1.5.10

**Download `BeeboScore-1.5.10.exe`** below. Already on BeeboScore? Open **Settings → Check for updates** and it fetches this one for you.

### The sets sections, fixed

- **Obsidian Glass on Street Fighter 6:** the box behind the set pips follows your colours now. In a light colour set (like Sakura) it was black.
- **At the end of a set** the winner's set pips stay lit on Street Fighter 6, Avatar Legends and Fatal Fury. They went dark and looked unlit.
- **Classic on Fatal Fury:** the bars keep their black shadow in every colour set, like the set boxes.

The full list of changes is in [CHANGELOG.md](https://github.com/t1fgc/beeboscore/blob/main/CHANGELOG.md).

### Windows SmartScreen

The first time you run the exe, Windows may say **"Windows protected your PC"**. Click **More info**, then **Run anyway**. Only do this for a copy downloaded from this Releases page.

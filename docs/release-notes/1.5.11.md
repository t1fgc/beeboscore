## BeeboScore 1.5.11

**Download `BeeboScore-1.5.11.exe`** below. Already on BeeboScore? Open **Settings → Check for updates** and it fetches this one for you. (The `BeeboScore-Lite-1.5.11.exe` file is the same app, named so 1.5.0 can find it.)

### What's fixed

- **Obsidian Glass on Tekken 8:** the round counters show through the player bars whole. The bar covered the bottom-left of each counter.
- **Light colour sets (like Sakura):** the lettering on the VS, Victory, Top 8, bracket, standings and game-format screens is easy to read. Pale lettering used to fade into the light plates; it's a deeper shade of its colour now. Dark colour sets look exactly as before.

The full list of changes is in [CHANGELOG.md](https://github.com/t1fgc/beeboscore/blob/main/CHANGELOG.md).

### Windows SmartScreen

The first time you run the exe, Windows may say **"Windows protected your PC"**. Click **More info**, then **Run anyway**. Only do this for a copy downloaded from this Releases page.

## BeeboScore 1.5.7

**Download `BeeboScore-1.5.7.exe`** below. Already on BeeboScore? Open **Settings → Check for updates** and it fetches this one for you.

### Fixes for the layout maker

- **The layout maker closes when you click X.** It wouldn't close before. If you've made changes, it asks whether to **Save**, **Don't save** or **Keep editing**.
- **Closing BeeboScore with the layout maker open closes the whole app.** Before, the app could keep running out of sight and wouldn't open again until you ended it in Task Manager. If that happened to you, end **BeeboScore** in Task Manager once, then update.
- **Edit** or **Make your own** on the Layouts tab asks before it replaces changes you haven't saved in the layout maker.
- The arrow keys on a slider in the side panel move the slider, not the piece.
- **Escape** closes the layout maker's questions.
- A layout can't be saved under the name of one of the app's own layouts any more.

The full list of changes is in [CHANGELOG.md](https://github.com/t1fgc/beeboscore/blob/main/CHANGELOG.md).

### Windows SmartScreen

The first time you run the exe, Windows may say **"Windows protected your PC"**. Click **More info**, then **Run anyway**. Only do this for a copy downloaded from this Releases page.

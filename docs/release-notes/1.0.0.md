## BeeboScore 1.0.0

A free scoreboard overlay for fighting game streams. **This is a prototype build** — a fuller build is on the way later in 2026.

### Download
**`BeeboScore-1.0.0.exe`** below. No install: put it in a folder of its own and run it.

> [!WARNING]
> Windows may show **"Windows protected your PC"** the first time you run it. Click **More info**, then **Run anyway**. Windows shows this for new apps that not many people have downloaded yet. Only do this for a file downloaded from this page.

### In this build
- **Matches**, with one-press score keys, Swap, Reset and Undo
- **Shattered**, the built-in animated layout, for every fighting game
- **Overlay maker:** drop in a PNG overlay and get an animated layout that matches its style
- **start.gg:** load your event, pull players and matches, send results back
- **Go online:** a public overlay link and a remote control for your phone
- **Stream Deck** plugin built in
- **Settings → Check for updates**

### Coming later in 2026
- Multiple supported game formats: Team Battle, KOTH, Death Battle and more
- Twitch integration for Viewer Battles and Tournaments
- Bracket Generator with custom overlays
- Layout Designer with so many features creators will love to start creating their own overlays!
- And more!

### Set-up
In OBS, add a **Browser** source with the URL `http://localhost:3300/overlay`, width 1920, height 1080.
